# 9. Palindrome Number

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/palindrome-number/

## Description

Given an integer `x`, return `true` if its decimal representation reads the same forward and backward; otherwise, return `false`. Negative numbers are not palindromes.

## Examples

**Example 1**
```text
Input: x = 121
Output: true
```

**Example 2**
```text
Input: x = -121
Output: false
```

**Example 3**
```text
Input: x = 10
Output: false
```

## Constraints

- `-2^31 <= x <= 2^31 - 1`
