# 344. Reverse String

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/reverse-string/

## Description

Reverse the input character array in place, using only constant extra space.

## Examples

**Example 1**
```text
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

**Example 2**
```text
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

## Constraints

- `1 <= s.length <= 10^5`
- `s[i]` is a printable ASCII character.
