# 1. Two Sum

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/two-sum/

## Description

Given an integer array `nums` and an integer `target`, return the indices of two distinct elements whose values add up to `target`. Exactly one valid answer exists; the indices may be returned in either order.

## Examples

**Example 1**
```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```

**Example 2**
```text
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

**Example 3**
```text
Input: nums = [3,3], target = 6
Output: [0,1]
```

## Constraints

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- Exactly one valid answer exists.
