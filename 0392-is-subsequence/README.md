# 392. Is Subsequence

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/is-subsequence/

## Description

Given strings `s` and `t`, determine whether `s` is a subsequence of `t`. A subsequence is formed by deleting zero or more characters without changing the order of the remaining characters.

## Examples

**Example 1**
```text
Input: s = "abc", t = "ahbgdc"
Output: true
```

**Example 2**
```text
Input: s = "axc", t = "ahbgdc"
Output: false
```

**Example 3**
```text
Input: s = "", t = "ahbgdc"
Output: true
```

## Constraints

- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- `s` and `t` consist only of lowercase English letters.
