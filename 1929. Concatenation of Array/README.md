# 1929. Concatenation of Array

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/concatenation-of-array/

## Description

Given an integer array `nums`, return an array formed by appending a second copy of `nums` to the end of the first copy.

## Examples

**Example 1**
```text
Input: nums = [1,2,1]
Output: [1,2,1,1,2,1]
```

**Example 2**
```text
Input: nums = [1,3,2,1]
Output: [1,3,2,1,1,3,2,1]
```

**Example 3**
```text
Input: nums = [1,1]
Output: [1,1,1,1]
```

## Constraints

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^5`
