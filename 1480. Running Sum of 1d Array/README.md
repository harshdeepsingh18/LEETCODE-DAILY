# 1480. Running Sum of 1d Array

- **Difficulty:** Easy
- **LeetCode:** https://leetcode.com/problems/running-sum-of-1d-array/

## Description

Given an array `nums`, return its running sum, where each output element is the sum of the input elements from index `0` through that index.

## Examples

**Example 1**
```text
Input: nums = [1,2,3,4]
Output: [1,3,6,10]
```

**Example 2**
```text
Input: nums = [1,1,1,1,1]
Output: [1,2,3,4,5]
```

**Example 3**
```text
Input: nums = [3,1,2,10,1]
Output: [3,4,6,16,17]
```

## Constraints

- `1 <= nums.length <= 1000`
- `-10^6 <= nums[i] <= 10^6`
